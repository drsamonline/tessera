# 08 - Learning (Layer 7)

**Status: Frozen**

A new user reaches the activation event without a consultant. Ten artefacts, each with an acceptance criterion
in [16-acceptance-criteria.md](16-acceptance-criteria.md).

| # | Artefact | Purpose |
|---|---|---|
| 1 | Role-aware bootcamp | Solo founder, sales rep, admin, support &mdash; each routed to the activation event |
| 2 | In-app coach | Contextual tips and a show-me-how overlay |
| 3 | Help panel (`?`) | Plain-English glossary, generated from the jargon map |
| 4 | Academy v1 | Five task-based videos of 2-5 minutes plus an interactive sandbox |
| 5 | Migration assistant | Field mapping, validation, dry run, rollback |
| 6 | Onboarding email drip | Day 0, 3, 7, 30 |
| 7 | Documentation site | Guides, API reference, glossary, changelog |
| 8 | User-facing changelog | Per-persona summaries of what changed |
| 9 | Community platform | Template exchange |
| 10 | In-product glossary | Generated from the jargon map so it cannot drift |

All learning content is versioned with the product. A user-visible concept change must update help content in
the same release; the release check fails otherwise.

v2 adds a full academy (30+ videos), certification tracks, office hours and a public roadmap.
